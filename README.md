## What it does

`main.ts` writes a single line of text (1–240 characters) to `/output/entry.txt`: a quiet, earned moment of pride — after two years of evening classes, a grandmother reads her granddaughter a whole bedtime story without stopping once.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (TypeScript runs natively).
